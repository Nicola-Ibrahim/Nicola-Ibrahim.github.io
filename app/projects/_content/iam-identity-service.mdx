## Overview

When several applications each implement login, the same work is repeated
and changes become harder to manage. This project explores a shared
authentication service.

## Approach

The service uses Django REST Framework for registration and login. It
issues JWT access tokens, supports refresh tokens, and keeps a blocklist
for tokens that have been revoked at logout.

## What it demonstrates

The project demonstrates token lifecycle design and the trade-offs of
centralizing authentication. It is a concept project rather than a
deployed identity system.
