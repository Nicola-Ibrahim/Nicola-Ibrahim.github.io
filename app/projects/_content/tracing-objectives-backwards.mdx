## Overview

Engineering design often starts with a desired result but no clear set of
inputs to produce it. This project explores the reverse problem: given a
target, search for possible parameter combinations. When an exact match
is unavailable, the search can return a nearby option.

## Approach

FastAPI handles requests while a separate Python module runs the search.
NumPy and SciPy support the numerical work. The API and search code are
kept separate so each can be changed and tested independently.

## What it demonstrates

The project demonstrates optimization work behind an API, including how to
handle targets with several possible answers or no exact match.
