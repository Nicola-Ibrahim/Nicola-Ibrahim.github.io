## Overview

AI providers return different response formats, which complicates an
application that uses more than one. This backend prototype explores a
single interface for calling several providers.

## Approach

The FastAPI service sends requests through provider adapters. Each adapter
translates a provider's response into a common format before the rest of
the application uses it. PostgreSQL holds the conversation state.

## What it demonstrates

The project demonstrates external AI API integration while keeping
provider-specific code in one place. It remains a prototype rather than a
production service.
