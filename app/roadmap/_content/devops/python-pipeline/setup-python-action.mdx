---
title: "Marketplace Actions: setup-python"
shortDesc: "The fastest way to install Python environments."
---

Setting up programming languages manually using bash scripts (`apt-get install python3`) is slow and prone to breaking when OS mirrors go down.

**The Marketplace Advantage**

- **`actions/setup-python`:** This official action instantly provisions exact Python versions (e.g., `3.11.2`) using pre-compiled binaries cached by GitHub.
- **Matrix Testing:** You can easily pass a list of versions to test your code against multiple Python environments simultaneously.
- **Dependency Caching:** It has built-in support for `pip`, `pipenv`, and `poetry`. With one flag, it automatically caches your downloaded packages to drastically speed up future pipeline runs.
