Running unit tests is computationally expensive. You don't want to waste 5 minutes running tests just to find out a developer forgot a trailing comma or left an unused import.

**The Shift-Left Philosophy**

- **Fail Fast:** Place code formatting (Black) and linting (Ruff/Flake8) as the very first steps in your CI pipeline.
- **Enforcing Standards:** If `black --check .` detects poorly formatted code, the pipeline crashes instantly. This removes subjective arguments in Code Reviews—the CI pipeline becomes the bad guy.
- **Speed:** Tools like Ruff are written in Rust and can lint thousands of lines of Python in milliseconds.
