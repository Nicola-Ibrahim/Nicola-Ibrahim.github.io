# Trees, Tries & Heaps

## Binary Trees & BSTs

Trees are inherently recursive data structures. Mastering them requires a deep understanding of recursive stack frames and gravitational data flow.


| Concept | Logic | Complexity |
| --- | --- | --- |
| **DFS** | Depth-First (Stack/Recursion) | Time: O(N), Space: O(H) |
| **BFS** | Breadth-First (Queue) | Time: O(N), Space: O(W) |
| **BST Search** | Left < Root < Right | Time: O(log N) average |


### Traversal Patterns

- **DFS Traversals:** Master Pre-order (Root-L-R), In-order (L-Root-R), and Post-order (L-R-Root). For a BST, In-order traversal visits nodes in sorted order.
- **Level Order (BFS):** Useful for finding the shortest path or processing nodes layer-by-layer.
- **Recursion Flow:** Understand how data flows **DOWN** via parameters and **UP** via return values.


> [!tip] Balanced Trees
> A BST is only **O(log N)** if it is balanced. In the worst case (a single long line), it degenerates into a Linked List with **O(N)** complexity.

## Heaps & Priority Queues

Heaps are specialized complete binary trees that satisfy the heap property—parent nodes are always smaller (Min-Heap) or larger (Max-Heap) than their children.

## Running Optimizations

- **O(1) Access:** Instantly retrieve the highest priority element.
- **Push/Pop Complexity:** Both operations take **O(log N)** to re-balance the heap.
- **Two-Heap Pattern:** Use a Max-Heap and Min-Heap together to track the **running median** of a data stream in real-time.


> [!warning] Python's heapq
> Python's built-in `heapq` module is a **Min-Heap**. To simulate a Max-Heap, you must negate all numbers (multiply by -1) before pushing them.

## Tries (Prefix Trees)

Tries store characters in nodes, sharing common prefixes to save memory and enable lightning-fast string validation.

## Prefix Efficiency

- **O(L) Complexity:** Searches take time proportional to the word length (L), regardless of how many millions of words are in the dictionary.
- **DFS + Trie:** This combination is the key to solving complex "Word Search" problems where you must explore a grid to form words.
- **Autocomplete:** Tries are the foundational structure behind search bar suggestions and spell checkers.


| Feature | Hash Set | Trie |
| --- | --- | --- |
| **Exact Match** | O(1) | O(L) |
| **Prefix Match** | O(N) | O(L) |
| **Space** | Sparse | Dense (Shared) |



> [!ai] Trie implementation tip
> Each node in a Trie typically contains a flag `is_end_of_word` and a dictionary/array of children mapping characters to more nodes.
