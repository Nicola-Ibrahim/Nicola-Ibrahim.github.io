>
Trees are inherently recursive data structures. Binary Search Trees (BST) add the property that left children are smaller, right are larger.

- **DFS Traversals:** Master Pre-order, In-order, and Post-order recursive visits.
- **The Call Stack:** Understand how data flows UP the recursive stack (return values) and DOWN (parameters).
- **BFS Level Order:** Using a Queue to process a tree layer by layer.
</Topic>

  shortDesc="Maintaining running minimums and maximums in O(1) time."

>
Heaps are complete binary trees that satisfy the heap property, used to quickly fetch the largest or smallest element.

- **O(1) Min/Max Access:** Instantly retrieve the highest priority element.
- **Top K Problems:** The most efficient way to find the Kth largest element in a stream.
- **Running Medians:** Using a Max-Heap and Min-Heap together to track medians dynamically.
</Topic>

<Topic

  title="3. Tries (Prefix Trees)" 
  shortDesc="Tree-like structures for hyper-efficient string matching."

Tries store characters in nodes, making them incredibly fast for word validation and prefix searches.

- **O(L) Time Complexity:** Searches take time proportional to the length of the word (L), not the number of words.
- **Autocomplete Systems:** The foundational data structure behind search bar suggestions.
- **Efficient Storage:** Shares common prefixes to save memory compared to Hash Sets.
</Topic>
