  title="1. Backtracking" 
  shortDesc="Exploring all possibilities and abandoning dead ends."
  links={[
    { label: "Subsets", url: "https://leetcode.com/problems/subsets/" },
    { label: "Combination Sum", url: "https://leetcode.com/problems/combination-sum/" },

    { label: "Word Search", url: "https://leetcode.com/problems/word-search/" }
  ]}
>
Backtracking explores all possibilities by aggressively pruning dead ends via recursion.

- **The Core Pattern:** Make a choice, recurse, then *undo* the choice (backtrack) to explore the next path.
- **Combinatorics:** Essential for generating all combinations, permutations, or subsets.
- **Pruning:** Adding conditions to stop recursing early when a path is guaranteed to fail.
</Topic>

>
Graphs represent relationships between entities using nodes and edges.

- **Breadth-First Search (BFS):** Uses a Queue. Ideal for finding the shortest path in unweighted graphs.
- **Depth-First Search (DFS):** Uses a Stack or recursion. Ideal for exhaustive searches and island counting.
- **Union Find (Disjoint Set):** An advanced structure perfect for grouping connected components or detecting cycles.
</Topic>

  title="3. Advanced Graphs (Shortest Path)" 
  shortDesc="Dijkstra's, Bellman-Ford, and Minimum Spanning Trees."
  links={[

>
Advanced graphs deal with weighted edges where simple BFS/DFS isn't enough to find the cheapest route.

- **Dijkstra's Algorithm:** Uses a Min-Heap to find the shortest path in graphs with positive weights.
- **Bellman-Ford:** Capable of finding shortest paths even with negative edge weights.
- **Minimum Spanning Trees:** Kruskal's or Prim's algorithms connect all nodes with minimal total cost.
</Topic>
