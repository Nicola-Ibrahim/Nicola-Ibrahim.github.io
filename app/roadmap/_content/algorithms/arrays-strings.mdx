# Arrays, Strings & Searching

## Arrays, Strings & Hash Maps

Hash maps trade space for time, giving you **O(1)** average lookups. This is almost always the first optimization step when moving away from a brute-force **O(N²)** solution.


| Technique | Goal | Complexity |
| --- | --- | --- |
| **Frequency Counter** | Count occurrences (Anagrams) | Time: O(N), Space: O(K) |
| **Prefix Sum** | Range Sum Queries | Time: O(N) pre-calc |
| **Index Mapping** | Store value -> index (Two Sum) | Time: O(1) Lookup |


## Core Patterns

- **Hashing:** Use a dictionary (Python) or Map (JS) to store the presence of elements.
- **Strings as Arrays:** Most string problems are just array problems where the elements are characters.
- **Fixed Size Arrays:** If the character set is limited (e.g., lowercase a-z), use an array of size 26 instead of a full hash map to save space overhead.


> [!tip] Pro Tip: Sorting vs Hashing
> If the problem asks for constant space **O(1)** and allows modifying the input, try **Sorting** first. If not, a **Hash Map** is usually the faster solution.

## Binary Search

Binary search isn't just for finding elements in a sorted array; it's a powerful divide-and-conquer strategy that slashes search space in half at every step.

### The Mechanics

```python
while left <= right:
    mid = left + (right - left) // 2
    if target == arr[mid]:
        return mid
    elif target < arr[mid]:
        right = mid - 1
    else:
        left = mid + 1
```

- **O(log N) Time:** Efficiently handles millions of items in under 20 steps.
- **Search on Answer:** Used to find optimal solutions in a range (e.g., *"What is the minimum speed needed to eat all bananas in H hours?"*).
- **Key Challenge:** identifying the **Monotonic Property** (True/False boundary) and managing left/right pointer edge cases.


> [!warning] Integer Overflow
> Avoid `(left + right) // 2`. In languages like Java/C++, this can cause overflow. Always use `left + (right - left) // 2`.

## Two Pointers & Sliding Window

Two Pointers involve traversing an array from different directions. Sliding Window is a special subset used to find contiguous subarrays or substrings.

### Techniques Breakdown


- **Opposite Ends:** Move `left` and `right` pointers inward to find pairs or validate palindromes.
- **Fast & Slow:** Useful for cycle detection in linked lists (not strictly array-based but a core pointer concept).
- **Sliding Window:** Expand the window by moving the `right` pointer, and shrink it by moving the `left` pointer when a constraint is violated.


| Strategy | When to use? | Complexity |
| --- | --- | --- |
| **Two Pointers** | Sorted arrays, finding pairs | Time: O(N) |
| **Fixed Window** | Subarray of size K | Time: O(N) |
| **Variable Window** | Longest/Shortest subarray | Time: O(N) |



> [!info] Why linear time?
> Even though there are two pointers, each element is visited at most **twice** (once by the right pointer, once by the left). This keeps the complexity at **O(2N)** which simplifies to **O(N)**.
