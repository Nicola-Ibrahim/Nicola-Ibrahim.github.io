    { label: "Group Anagrams", url: "https://leetcode.com/problems/group-anagrams/" },
    { label: "Top K Frequent Elements", url: "https://leetcode.com/problems/top-k-frequent-elements/" }
  ]}
>
Hash maps trade space for time, giving you O(1) lookups. This is usually the first optimization step in brute-force O(N^2) array problems.

- **Frequency Counters:** Count occurrences of elements to quickly solve anagram or duplicate problems.
- **Prefix Sums:** Pre-calculate running totals to optimize subarray computations.
- **Index Mapping:** Store elements alongside their indices for fast retrieval (e.g., Two Sum).
</Topic>

  id="binary-search" 
  title="2. Binary Search" 
  shortDesc="Divide and conquer in O(log N) time on sorted data."
  links={[

    { label: "Search a 2D Matrix", url: "https://leetcode.com/problems/search-a-2d-matrix/" },

  ]}
>
Binary search isn't just for finding elements in a sorted array; it's a powerful divide-and-conquer strategy.

- **O(log N) Time:** Slashes search space in half at every step.
- **Search on Answer:** Used to find optimal solutions in a range (e.g., Koko Eating Bananas).
- **Key Challenge:** Identifying the monotonic property and managing left/right pointer edge cases.
</Topic>

Two Pointers are used when traversing sorted arrays or finding pairs. Sliding Window is a subset used to find contiguous subarrays.

- **Opposite Ends:** Move left and right pointers inward to find pairs (e.g., Valid Palindrome).
- **Sliding Window:** Expand the window by moving the right pointer, and shrink it by moving the left pointer.
- **Optimization:** Converts nested O(N^2) loops into linear O(N) time.
</Topic>
