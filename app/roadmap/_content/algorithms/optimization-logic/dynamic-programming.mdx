Dynamic Programming solves complex problems by caching the results of overlapping subproblems.

- **Memoization (Top-Down):** Start with a recursive tree and cache the results to prevent duplicate work.
- **Tabulation (Bottom-Up):** Build the solution iteratively using an array or matrix.
- **Identifying DP:** Look for questions asking for the \"maximum/minimum\" or \"number of ways\" involving overlapping decisions.
