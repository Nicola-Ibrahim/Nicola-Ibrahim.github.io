shortDesc: "Replacing manual UI clicks with readable code."
---

Replacing manual UI clicks with readable, version-controlled code.

- **Declarative Syntax:** You declare *what* you want in HashiCorp Configuration Language (HCL), and Terraform figures out *how* to build it.
- **Version Control:** Infrastructure can be peer-reviewed and tracked in Git just like application code.
- **Idempotency:** Running the code multiple times only applies the necessary changes (the diff).
