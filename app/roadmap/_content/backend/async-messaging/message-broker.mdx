title: "5. The Message Broker (Infrastructure)"
shortDesc: "The physical software engine that hosts your Queues and Event Buses."
---

The physical software engine (RabbitMQ, Kafka, Redis) that hosts your Queues and Event Buses.

- **🏛️ The Golden Rule:** Queues are for **Commands** (Do this action once). Event Buses are for **Events** (This fact happened, react to it).
