A powerful architectural tool that scans folder trees and builds visual dependency graphs.

- **Read-Only Scanning:** Safely maps dependencies without modifying core files.
- **Mermaid.js Output:** Generates beautiful visual diagrams of your system architecture.
- **Smart Filtering:** Automatically ignores `node_modules` or `venv` directories.
