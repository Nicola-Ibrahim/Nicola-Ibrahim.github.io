This skill forces the AI to check mockups and wireframes in the resources folder before writing frontend code.

- **Visual Guide Analysis:** Prevents generic or mismatched UI generation by reviewing design files.
- **Brand Alignment:** Enforces a specific tone, brand voice, and CSS framework rules.
- **Standardization:** Automatically generates an ideal component boilerplate matching reference images.
