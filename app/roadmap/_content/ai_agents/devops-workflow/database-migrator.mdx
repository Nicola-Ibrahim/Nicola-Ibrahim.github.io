Provides the agent with ORM conventions and mandates aggressive warnings for destructive actions.

- **Data Loss Warnings:** Boldly warns if a migration risks dropping tables or deleting data.
- **Naming Conventions:** Enforces snake_case or camelCase matching your specific ORM.
- **Safe Scaffolding:** Uses automated scripts to generate the migration file without auto-applying it.
