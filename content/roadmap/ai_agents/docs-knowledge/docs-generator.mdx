Teaches the AI to read source code routes and output structured markdown documentation.

- **Auto-Updating:** Keeps READMEs and inline comments perfectly in sync with codebase changes.
- **API Formatting:** Formats outputs strictly to standards like OpenAPI or Swagger.
- **Clear Layouts:** Follows an example route documentation template to ensure consistency.
