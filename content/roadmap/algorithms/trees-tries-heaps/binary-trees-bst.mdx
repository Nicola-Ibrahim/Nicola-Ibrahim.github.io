Trees are inherently recursive data structures. Binary Search Trees (BST) add the property that left children are smaller, right are larger.

- **DFS Traversals:** Master Pre-order, In-order, and Post-order recursive visits.
- **The Call Stack:** Understand how data flows UP the recursive stack (return values) and DOWN (parameters).
- **BFS Level Order:** Using a Queue to process a tree layer by layer.
