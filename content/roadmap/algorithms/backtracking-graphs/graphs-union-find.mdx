Graphs represent relationships between entities using nodes and edges.

- **Breadth-First Search (BFS):** Uses a Queue. Ideal for finding the shortest path in unweighted graphs.
- **Depth-First Search (DFS):** Uses a Stack or recursion. Ideal for exhaustive searches and island counting.
- **Union Find (Disjoint Set):** An advanced structure perfect for grouping connected components or detecting cycles.
