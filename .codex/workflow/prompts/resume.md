# Resume an existing task

```text
Use $portfolio-change to continue .codex/workflow/tasks/<task-name>.md.

Follow AGENTS.md. Re-read the task and inspect the current working tree. Reconcile
the recorded state with actual files and checks. Continue only within the
previously authorized scope; a plan-only task remains plan-only. Preserve
unrelated changes. Delegate only when an independent, bounded answer will change
the next step; use at most one agent by default and ask for a concise handoff.
Run only checks needed for unfinished work, then update the task with actual
results, remaining limits and the next concrete action.
```
