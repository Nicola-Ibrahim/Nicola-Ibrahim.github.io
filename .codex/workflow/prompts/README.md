# Prompts

Copy a prompt, replace its placeholders, and send it in Codex. These files are
manual starting points, not executable automation.

| Goal | Prompt |
| --- | --- |
| Investigate and plan | [Plan](plan.md) |
| Implement an approved task | [Implement](implement.md) |
| Continue an existing task | [Resume](resume.md) |

Use `.codex/workflow/tasks/` for substantial task records. Small, clear fixes do
not need a task file. A planning request does not authorize implementation.
