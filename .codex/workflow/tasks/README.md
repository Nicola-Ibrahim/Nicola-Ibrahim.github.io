# Task records

Use one Markdown task record for substantial work that needs a plan or handoff.
Create it from `../templates/task.md`, give it a short descriptive filename, and
keep the current state and actual verification near the top. Small isolated fixes
do not need a record.

Task records document scope and evidence; they do not authorize implementation,
deployment or other external actions. Preserve older records unless asked to
remove them. Do not include secrets or private credentials.
